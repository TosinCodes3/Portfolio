DROP YOUR PROJECT IMAGES IN THIS FOLDER
========================================

You can drop your PNGs here with ANY names. Tell Claude which PNG belongs
to which project and it will convert each one to an optimized .webp with
the correct name below (and delete the heavy PNG afterward).

Target names the site looks for:

  1. miami-intensive.webp   ->  Miami 5-Day Intensive   (WIDE, ~16:10)
  2. viral-carousel.webp     ->  The Viral Carousel      (WIDE, ~16:10)
  3. opening-deck.webp       ->  Day 1 Opening Deck      (TALL, ~4:5)
  4. faded-culture.webp      ->  Faded Culture           (TALL, ~4:5)
  5. cut-series.webp         ->  The $100 Cut Series     (TALL, ~4:5)

Notes
-----
- PNGs are converted to WebP at quality ~82 and capped at 1600px on the
  long edge. Expect roughly 10-20x smaller files with no visible loss.
- Images display in grayscale by design (editorial look). Ask Claude to
  switch to full color if you prefer.
- Until a .webp exists, the slot shows its placeholder automatically.
